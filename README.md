# markov-matrix

Un test delle matrici di Markov per il calcolo delle probabilità e simulazione del degrado strutturale (ponti e infrastrutture).

## 📌 Descrizione

Il modello simula la probabilità di transizione tra 5 stati di condizione (Condition States, CS1–CS5) lungo un arco temporale di 125 anni, mostrando:
- La **matrice di transizione** delle probabilità;
- Il grafico dinamico dell'evoluzione delle distribuzioni nel tempo mediante **Chart.js**.

## 🛠️ Tecnologie utilizzate

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- [Chart.js](https://www.chartjs.org/) (via CDN)

## 🚀 Utilizzo

Apri direttamente il file `index.html` in un qualsiasi browser web moderno.
